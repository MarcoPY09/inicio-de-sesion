Diseño Web

CSS

CSS no es realmente un lenguaje de programación, tampoco es un lenguaje de marcado. Es un lenguaje de hojas de estilo, es decir, permite crear páginas de una manera más exacta y aplicarles estilos (colores, márgenes, formas, tipos de letras, etc.) de manera selectiva a elementos en documentos HTML por lo que se tiene mayor control de los resultados finales.

¿Para qué sirve el CSS?

La tecnología CSS está diseñada para marcar la separación del contenido de las páginas web y la forma de presentación de estas. Lo que genera múltiples beneficios, como: •Presentar el documento final en diferentes estilos (pantalla, voz, impresión). •Evitar hacer archivos demasiado pesados. •Definir el estilo visual de todo un sitio web. •Trabajar con estándares y separar (hasta cierto punto) la estructura de la presentación logrando un trabajo más definido. •Simplifica la creación de la página.

El HTML y CSS tienen una relación muy fuerte entre ellos, ya que el HTML es un lenguaje de marcado (constituye la base de un sitio web) y CSS define el estilo de la página (toda la parte estética).

Ventajas de CSS

🎨 Diseño atractivo

CSS permite cambiar colores, tamaños, fuentes, bordes y otros elementos para crear páginas web más atractivas.

⚡ Fácil de modificar

Puedes cambiar el diseño de varios elementos de una página modificando solamente unas pocas reglas de CSS.

📱 Diseño adaptable

CSS permite crear páginas que se adapten a computadoras, tablets y teléfonos celulares.
